# 품의서 메이커 · Approval Maker

견적서의 품목과 금액을 읽어 **사용자가 제공한 품의서 양식**에 입력하는 Windows용 로컬 프로그램입니다. 견적서마다 품의서를 하나씩 생성합니다.

현재 버전: **v0.2.4** · Python 3.11 이상 · Windows

## 주요 기능

- PDF·XLS·XLSX·XLSM 견적서에서 품목·수량·단가·금액을 추출하고 직접 검토·수정합니다.
- 사용자 양식의 엑셀 셀 또는 PDF 입력 영역에 항목을 연결합니다.
- 원본 양식과 같은 형식으로 견적서별 품의서를 생성합니다.
- 별도 부가세는 품목별 단가·금액에 포함합니다. 이미 포함된 부가세는 중복 가산하지 않습니다.
- 정수 단가로 나누어떨어지지 않으면 동일 품목을 두 행으로 나누어 수량과 총액을 유지합니다.
- **3. 일괄 생성**에서 견적서 총액·품의서 총액·차액·일치 여부를 바로 확인합니다.
- **저장 폴더는 사용자가 직접 지정합니다.** 프로그램이 정한 기본 출력 폴더는 없습니다.
- 파일은 로컬에서 처리하며 외부 AI API나 서버로 전송하지 않습니다.

자동 추출 결과는 원본과 대조해야 합니다. 모든 업체의 견적서나 모든 품의서 양식을 자동으로 이해하는 방식은 아닙니다.

## 내려받기와 실행

1. 이 저장소의 **Code → Download ZIP**을 눌러 내려받고 압축을 풉니다.
2. PC에 **Python 3.11 이상**이 없다면 [Python 공식 홈페이지](https://www.python.org/downloads/windows/)에서 설치합니다. 설치 시 **Add Python to PATH**와 Tcl/Tk 지원을 포함하세요.
3. 압축을 푼 폴더에서 **`install.bat`**을 한 번 실행합니다. 필요한 패키지 설치에는 인터넷 연결이 필요합니다.
4. 설치가 끝나면 **`start.bat`**을 더블 클릭합니다.
5. 처음에는 **샘플로 체험**을 눌러 가상 견적서와 빈 양식으로 확인할 수 있습니다.

이 저장소는 Python 소스 배포본입니다. Python 없이 실행하는 EXE 설치본은 포함하지 않습니다.

**XLS 양식으로 출력하려면 Windows용 Microsoft Excel이 설치되어 있어야 합니다.** PDF·XLSX 출력은 Excel 설치 없이 가능합니다.

수동 설치 및 실행:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 사용 순서

### 1. 견적서 검토

1. **견적서 추가**에서 PDF 또는 엑셀 파일을 선택합니다. 여러 파일도 가능합니다.
2. 추출된 공급업체·견적일·품목·수량·단가·금액을 원본과 대조합니다.
3. **원본 품목 금액에 부가세 포함** 여부를 확인합니다. 별도 부가세는 원본에 표시된 금액을 입력합니다.
4. **합계금액에는 원본 견적서의 부가세 포함 총액을 입력합니다.** 총액이 없으면 비교할 수 없어 생성하지 않습니다.
5. **검토 완료 → 다음 단계**를 누릅니다. 검토할 견적서가 더 있으면 다음 견적서로 이동합니다.

검토 화면에는 원본 금액을 유지합니다. 품목은 추가·수정·삭제할 수 있으며, **금액 계산**은 비어 있는 품목 금액과 합계를 계산합니다. 계산한 합계도 반드시 원본과 대조하세요. 검토 후 내용을 수정하면 다시 검토가 필요합니다.

### 2. 양식 연결

1. **양식 선택**으로 비어 있는 품의서 양식을 선택합니다.
2. 첫 행에 `내용 / 규격 / 단위 / 수량 / 예상단가`처럼 열 제목만 있는 엑셀 표라면 **열 제목으로 자동 연결**을 누릅니다.
3. 다른 엑셀 양식은 항목별 시트·시작 셀·품목 칸 수·행 간격을 지정합니다. 병합 셀은 왼쪽 위 셀에 연결합니다.
4. PDF 양식은 비어 있는 입력 영역을 드래그하여 위치·폭·높이를 정합니다. 품목은 반복 칸 수와 간격도 지정합니다.
5. **빈 단위 기본값**에 `개` 등을 넣으면 원본에 단위가 없는 품목에만 적용합니다.
6. **연결 설정 저장**으로 JSON을 저장합니다. 다음에는 **연결 설정 불러오기**로 재사용할 수 있습니다.

프로그램 폴더의 `profiles`에 저장한 설정은 같은 내용의 양식을 선택할 때 자동으로 불러옵니다. 서로 다른 설정이 여러 개 있으면 사용할 설정을 직접 선택합니다. 양식이 변경되면 입력 위치를 다시 확인해야 합니다.

양식 파일만 선택하고 입력 위치를 연결하지 않은 경우에는 생성 전에 연결 화면으로 안내합니다. 출력 화면에서 **입력 위치 N개 연결됨**을 확인하세요.

### 3. 일괄 생성

1. **폴더 선택**을 눌러 결과를 저장할 폴더를 직접 지정합니다. 프로그램을 새로 실행하면 저장 폴더 칸은 비어 있습니다.
2. 목록의 **견적서 총액 / 품의서 총액 / 차액 / 총액 비교**를 확인합니다. 금액은 모두 부가세 포함 기준입니다.
3. 필요하면 **품의서 금액 미리보기**에서 품목별 금액과 나뉜 행을 확인합니다. 창 아래에도 두 총액과 차액을 표시합니다.
4. **선택 견적서로 시험 생성** 또는 **전체 품의서 생성**을 누릅니다.
5. 성공한 결과를 두 번 클릭하여 파일을 열고, 양식의 위치와 인쇄 모양을 확인합니다.

생성 전에는 **일치(예정)**, 생성이 성공하면 **일치 / 성공**으로 표시합니다. 총액이 다르면 **불일치**와 차액을 표시하고 해당 파일의 생성을 중단합니다. 다른 견적서는 계속 처리합니다.

기존 결과물은 덮어쓰지 않고 `_2`, `_3` 같은 번호를 붙입니다. 사용자가 지정한 폴더에 품의서와 `생성결과_날짜시간.json` 기록을 저장합니다. 기록에는 성공·실패 사유, 원본 총액, 출력 총액, 차액, 출력 품목이 포함됩니다.

## 금액 처리 기준

- 별도 부가세는 품목 공급가액에 비례하여 배분합니다. 원 미만 잔여는 잔여가 큰 품목부터 1원씩 배분해 총액을 유지합니다.
- 부가세가 비어 있으면 원본 총액에서 품목 공급가액 합계를 뺀 금액을 사용합니다. 세율 10%를 임의로 적용하지 않습니다.
- 예를 들어 3개의 부가세 포함 금액이 1,001원이면 **333원 × 1개 + 334원 × 2개**로 나눕니다. 품명·규격·단위·비고와 수량 합계를 유지합니다.
- 이미 부가세가 포함되어 있으면 다시 더하지 않습니다. 원본 단가의 반올림 차이가 있는 경우에도 품목 금액과 수량을 유지하도록 출력 행을 나눕니다.
- 출력 행의 **수량 × 단가 = 품목 금액**, **출력 품목 합계 = 원본 견적서 총액**을 검증합니다. 총액의 1원 차이도 허용하지 않습니다.
- 연결된 별도 부가세 금액 칸은 비웁니다. `품목 합계 (부가세 포함)`과 합계금액에는 부가세 포함 총액을 입력합니다.
- 검토 중 원본 숫자는 바꾸지 않으므로 반복 생성으로 부가세가 중복 가산되지 않습니다.

## 지원 범위와 주의 사항

| 구분 | 지원 |
| --- | --- |
| 입력 견적서 | 텍스트 PDF, XLS, XLSX, XLSM |
| 품의서 양식과 결과 | PDF, XLS, XLSX, XLSM — 양식과 같은 형식 |
| 일괄 처리 | 견적서 1개당 품의서 1개 |
| OCR | 선택 기능, Tesseract 및 `kor`, `eng` 언어 데이터 별도 설치 |
| XLS 저장 | Microsoft Excel의 별도 인스턴스로 사본 생성 |

- **검토 중 수정 내용은 프로그램 종료 시 저장되지 않습니다.** 연결 설정은 JSON으로, 생성한 품의서는 결과 파일로 보관합니다.
- HWP/HWPX, PDF↔엑셀 양식 자체 변환, 고정 양식의 자동 페이지 추가는 지원하지 않습니다.
- 복잡한 표, 여러 줄 헤더, 스캔 PDF는 추출 결과의 수동 보완이 필요할 수 있습니다.
- 정수 단가를 위해 나뉜 행까지 포함하여 양식의 입력 칸이 충분해야 합니다. 첫 행만 있는 엑셀 표는 자동 연결 시 최대 1,000행으로 설정합니다.
- PDF는 원본 위에 텍스트를 추가하므로 반드시 빈 입력 영역을 지정하세요. 사용자 양식의 고정 문구와 연결하지 않은 셀은 그대로 유지합니다.
- 수식 셀에는 직접 쓰지 않습니다. 수식의 입력 셀을 연결하세요. XLSX/XLSM의 수식은 Excel에서 열 때 다시 계산하도록 설정합니다.
- XLS의 새 행은 줄바꿈과 높이 자동 조정을 적용합니다. XLSX의 긴 내용은 원본 양식의 행 높이·열 너비를 조정해야 할 수 있습니다.
- PDF 출력은 맑은 고딕을 사용합니다. 다른 글꼴은 `APPROVAL_FONT` 환경변수에 한글 TTF 경로를 지정할 수 있습니다.
- 암호화·전자서명된 양식이나 특수 형식은 일반 빈 PDF/XLSX 사본을 준비하세요.
- OCR이 없는 환경에서도 원본을 열어 내용을 직접 입력할 수 있습니다.

## 개발 및 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

현재 72개 검사 항목이 있습니다. 공유 소스만으로 71개를 수행하며, 실제 비공개 PDF가 필요한 회귀 검사 1개는 기본적으로 건너뜁니다. 필요할 때 `APPROVAL_TEST_PDF` 환경변수로 해당 검증 파일의 경로를 지정합니다.

금액 배분·정수 단가 분리·총액 비교·원본 보존·생성 단계 이동·저장 폴더 직접 지정·연결 설정 재사용·PDF/XLSX 입출력·수식 셀 보호·기존 결과 보존 등을 검사합니다. XLS 저장은 Excel이 설치된 Windows에서 별도로 확인해야 합니다.

주요 구현:

- `approval_generator/gui.py`: 검토, 양식 연결, 총액 비교, 일괄 생성
- `approval_generator/extract.py`: PDF·엑셀 내용 추출
- `approval_generator/pricing.py`: 부가세 배분, 정수 단가 분리, 총액 검증
- `approval_generator/render.py`: XLSX/XML 부분 수정과 PDF 텍스트 삽입
- `approval_generator/legacy_excel.py`, `native_excel.ps1`: Microsoft Excel을 통한 XLS 사본 생성
- `approval_generator/demo.py`: 개인정보 없는 체험용 파일 생성

실제 견적서·품의서·사용자 연결 설정·로컬 Python 환경은 저장소에 포함하지 않습니다. 체험 파일은 프로그램의 **샘플로 체험**에서 생성할 수 있습니다.
